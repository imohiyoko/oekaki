# three-tier example

A public ALB in two public subnets, ECS services on two private subnets, and a
multi-AZ RDS instance. Small enough to read at a glance, complete enough to
exercise the parts of the parser that are easy to get wrong.

```console
$ oekaki render plan.json -o architecture.svg
```

![architecture](architecture.svg)

## What is here

| File | |
| --- | --- |
| `main.tf` | The Terraform this describes. Not applied by CI; it is here to be read, and for `--source-dir` to find line numbers in. |
| `plan.json` | `terraform show -json` output, checked in so the repository runs immediately after a clone |
| `graph.json` | The IR, regenerated by `make example` |
| `architecture.svg` | The diagram, regenerated by `make example` |
| `architecture.mmd` | The same graph as Mermaid |

`plan.json` has had its `resource_changes` array removed. That array is roughly
half the file, is a per-resource diff rather than anything structural, and the
parser never reads it. Everything else is as Terraform emits it.

## Things worth noticing in the output

**The bastion is inside `subnet: public-a`, but the load balancer is not inside
any subnet.** The bastion names one subnet, so that is where it goes. The load
balancer spans two, so it is drawn in the VPC that holds both. A multi-AZ
resource is not in one subnet and the diagram does not pretend otherwise.

**The ECS cluster and task definition sit outside the VPC.** They are regional
control-plane objects with no subnet of their own. That looks odd at first and
is correct.

**All four subnets are drawn, including the three that are empty.** Graphviz
discards an empty cluster, so the renderer inserts an invisible spacer to keep
them. An empty subnet is worth seeing.

**The RDS instance is placed via the DB subnet group.** It never names a subnet
directly; the parser walks one hop further out to find them.

## The interesting edge is the one you cannot see yet

`aws_security_group.db` allows PostgreSQL from `aws_security_group.bastion`.
Nothing in this stack ever opens that connection.

The graph records this as an `iac_ref` edge between two security groups —
the configuration dependency. With `reachable` enrichment it becomes
a path that is permitted and never used, which is the kind of thing this project
exists to make visible. The rule is in `main.tf` waiting for it.

## Regenerating

```console
$ make example          # rewrite graph.json, architecture.svg, architecture.mmd
$ make verify-example   # fail if regenerating changed anything
```

`verify-example` runs in CI. Because rendering is deterministic, it passes
unless behaviour genuinely changed — which makes it a test of determinism as
much as of output.
